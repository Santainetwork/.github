### 📡 Public RustDesk Relay Server

> [!TIP]
> Anda dapat memanfaatkan server relay publik kami secara gratis untuk koneksi RustDesk yang cepat, stabil, dan berlatensi rendah di Indonesia.

Masukkan konfigurasi berikut pada aplikasi klien **RustDesk** Anda (`Settings > Network`):

| Parameter | Nilai Konfigurasi |
| :--- | :--- |
| **ID Server (Rendezvous)** | `103.155.191.254` |
| **Relay Server** | `103.155.191.254` |
| **API Server** | *(Kosongkan / Opsional)* |
| **Key (Public Key)** | `Dir6U4JXUOKDeACqRwXhnv+QrxEMAuLcP7zdI9le3LU=` |

```ini
# Salin format satu baris untuk konfigurasi cepat:
```
